### D377. A person's text wins over the model's, by hand in the repo
- https://docs.weblate.org/en/latest/workflows.html — Weblate (a translation platform), "Translation workflows": an approved string "has been approved in the review. It can no longer be changed by translators, but only by reviewers"; automatic filling uses `state:empty` "to fill empty translations without replacing existing human work". Here the same rule: the reviewer is T9; a fixed text is used as it is, the model never translates it again, and it leaves the review list. T9 knows the Yoruba of the app's users, so T9's text is the one the app shows.
- The file is in the repo (`i18n/fixed.json`, edited by hand through the SUP, as `context.json`, `concepts.json` and `rules.json`), so every fixed text has a commit, a sources line and a review; no new route and no admin screen (Rosette shows the rounds, it does not edit).

### D378. A fixed text is tied to its English
- https://unicode-org.github.io/icu/userguide/format_parse/messages/ — ICU MessageFormat: the arguments of a message (`{name}`) are filled at run time; a translation must keep the same arguments. A fixed text with other `{name}` values than the English is not used (a warning).
- Each entry keeps the English it translates (`en`). When the app's English changes, the old fixed text could say the wrong thing, so the round does not use it, logs it, and translates the text again until a person writes a new one (as the round already does for a changed English text, `WorkList` "changed"). A language that is not a target, a text id that is not in the app, an empty or too long text: not used, a warning; the round does not stop on a bad entry or a bad file (a deploy must not fail on it).
- Tests: `TestActiveFixed`, `TestApplyFixed`, `TestRoundFixedText` (the fixed text is live, not in the work list, not on the review list, marked fixed with no score; a `fixed.json` change alone is a round with no model call; the next round is "nothing changed"; a changed English makes the entry old and the text is translated again). Mutation checks: without the pending check, without taking the text off the work list, or without applying it, `TestRoundFixedText` fails (measured).

Review (independent, 15 minutes at most): three defects and three small ones, all fixed. (1) A text taken out of `fixed.json` kept the person's text for ever (its English was in the source file, so no round came): now a live text marked fixed with no fixed text in use loses its source line and is translated again (`unfixed`; a round starts for it); the mark goes. (2) One unknown key or a typo in `fixed.json` stopped the whole round: unknown keys are left out, and a file that is not JSON is a warning (no fixed text is used); a typo of `text` is an empty text (a warning). (3) The fix round could send a fixed text to the model when a flagged text reached it through the graph, and the judges compared with the model's old text: the fix round now skips fixed texts and the checks see the person's text. Small: a text that reused a fixed text's translation (`same_as`) is its own text again; a stale fixed text kept after a failed try loses the mark; a model text that happens to be the same words gets the mark. Tests: `TestFixedTextNotInTheFixRound` (new), and `TestActiveFixed`, `TestApplyFixed`, `TestRoundFixedText` for the rest; mutation checks: without skipping fixed texts in the fix round, or without the source line removal, the tests fail (measured). The test translator (`round_test.go`) now counts the texts it gets.
