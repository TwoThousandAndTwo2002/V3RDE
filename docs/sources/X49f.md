### D266. Every file that listings embeds is copied into the post image, and a test checks it
- https://pkg.go.dev/embed — a //go:embed pattern that matches no file is a build error, and the files must be in the package's folder: the post image compiles the listings package, so its build context needs the file.
- https://docs.docker.com/build/concepts/context/#filename-and-location — the `<Dockerfile>.dockerignore` next to the Dockerfile sets the build context; a file it does not let in cannot be copied.
