### D39. The inventory timeout is 55 s, under the load balancer's 60 s
- https://docs.aws.amazon.com/elasticloadbalancing/latest/application/edit-load-balancer-attributes.html#connection-idle-timeout — the ALB idle timeout (default 60 s) closes a connection that sends no data for that time.
- https://www.rfc-editor.org/rfc/rfc9110#name-504-gateway-timeout — 504 Gateway Timeout.
- T9 decision 2026-10-27 (option b): keep 60 s on the load balancer; "no photo should take that long". The router's client waits 65 s and Caddy 70 s, so the service's own clear 504 reaches the caller.

### D40. Keep split 3 (no change to the live variant)
- https://platform.openai.com/docs/guides/latency-optimization — the latency principles: generate fewer tokens, make fewer requests, parallelize, make users wait less. More parallel calls each generate their own reasoning, so they cost more.
- https://dev.meta.ai/docs/pricing-rate-limits — reasoning tokens are billed as output tokens.
- Own evidence (`score_x31b_bench.json`): split 6 cut the median Muse wait from 10.4 s to 9.7 s for +47% cost ($0.0452 → $0.0665 per photo); output tokens per named box rose from 251 to 340, and the reasoning share from 56% to 68%.

### D41. `compact` is kept as an option that is off
- https://platform.openai.com/docs/guides/latency-optimization — fewer output tokens give a shorter wait.
- Own evidence: compact cut the output tokens per box by 8% (251 → 230) and the cost by 4%; the median wait changed from 10.4 s to 9.9 s. Too small to take the risk of a new answer format live; kept, with its test, for a later run (as two-pass, D21).

### D42. How the bench compares variants
- https://jmlr.org/papers/v22/20-303.html — Pineau et al., the ML reproducibility checklist: results from shared code and data, with the method stated.
- Every variant runs on each photo one after the other (the same API conditions); the Muse wait is the longest first-round call plus the retries (SAM is shared, so the engine total is not comparable). Names are compared with the X30b label of the same box; a new spelling has no label, so the bench gives no accuracy share. The unchanged control matched the labelled name on 150 boxes (297 in X30b): names change between runs.
