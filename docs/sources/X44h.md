### D181. The timer stays 30 minutes for everyone else
- https://api-security.owasp.org/editions/2023/en/0xa3-broken-object-property-level-authorization/ — an API must not let a caller change an object property the caller should not change.
- The 30-minute timer is the product rule (rescue starts only when it ran out; the feed shows only active listings). A short timer would let anyone hide a listing from the feed early, so only the accounts in `-test-ttl-emails` (compose `LISTINGS_TEST_TTL_EMAILS`: the five test accounts at example.org) may send `ttl_seconds`; any other caller gets 403. The field changes only the caller's own new listing.

### D182. 30 seconds is the shortest timer
- https://datatracker.ietf.org/doc/html/rfc2606 — example.org is reserved for documentation and tests, so no real user has these addresses.
- The rescue test needs a listing that expires with no claim; 30 s (T9's number) is enough for the test to post the seed, check that it is not yet expired, and then rescue it in the same run. The longest is the normal 30 minutes, so the field can only make a test shorter.
