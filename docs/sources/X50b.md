### D327. A store of every place found, by area, before the web search
- https://www.promptfoo.dev/docs/providers/meta/ — "Web search bills separately ($2.50 per 1,000 queries)" (R4), on top of the tokens of the search call. Each place the directory or the web search finds goes into `<data>/places.json` (the rescue volume) by area: the ZIP, else the point rounded to 0.1 degree (about 11 km). When the directory finds nothing or fails, the stored places of that area (found in the last 30 days) are the answer and the web search does not run. Only one copy of each place (name and address), at most 40 for an area (the newest), and no links of one rescue (tel, mailto, directions are made again for each rescue).
- https://creativecommons.org/licenses/by/4.0/ — the Feed America data is CC BY 4.0: it can be stored and used again with the credit; a stored web place keeps `source: "web_search"`, and an answer from the store gives the credit of the places as they were found (the web search credit when one of them came from it).
