(`inference/samcodec.go`), so on the X48k page every box mask was dropped ("sam: no mask for the item's box"). Cloud test: the box and point prompts of Compare now carry the metadata.

### D223. Box and point prompts send mask_encoding one_bit
- https://dev.meta.ai/docs/sam/segmenting — the docs say box and point prompts "always return one_bit masks, whatever mask_encoding you set"; the debug run above measured the "~" encoding without the setting, so the request states it.
- https://dev.meta.ai/docs/sam/reading-segmentation — "!" is the one_bit encoding that the codec reads; "~" is the lossless one it does not.
