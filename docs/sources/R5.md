### D259. A job that the app polls, with a ZIP only when the service asks
- https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-quotas.html — 30 s per request: the popup starts the job (`?async=1`, R4) and asks once a second, up to 100 s (longer than the 90 s job). The first POST has no body; the service then reads the ZIP of the pickup address (R3). Only its 400 "no ZIP" opens the ZIP field; a typed ZIP must be 5 digits (+4) before a request goes.
- The pickup field words ("Pickup address and instructions", example "12 Main St, Denver, CO 80219. Front desk") show a ZIP after a state code, the form the service reads (R3, D253).

### D260. The actions of an expired card at full strength; the place links 44 pt tall
- https://www.w3.org/TR/WCAG21/#contrast-minimum — 4.5:1 for text: the independent check measured the links of a gone card (`opacity.gone` 0.6 on the whole card) at about 3.3:1, so the fade is now on the photo and the title lines only.
- Independent code review: on Receive, the pickup line of a gone card is in the card's `extra`, so it fades on its own (as before R5).
- https://developer.apple.com/design/human-interface-guidelines/accessibility — 44 x 44 pt touch targets: `TextLink touch` adds `space.group` above and below the 20 pt line for "Directions", "Call" and "Email".

### D261. A dialog is at most `size.dialogMax` of the window height
- https://m3.material.io/foundations/layout/applying-layout/window-size-classes — a phone in landscape is a medium width, so it gets a dialog; the style guide already says a dialog is at most `size.dialogMax` of the window height, and the `Popup` dialog did not apply it (the independent check). It now does, and its frosted layer can shrink, so the scroll view of the places scrolls. This also holds for the other dialogs.

### D262. Only the service's own link kinds open
- https://genai.owasp.org/llm01/ — places can come from a web search (R4, untrusted text): the app opens only a Google Maps directions URL, `tel:` and `mailto:` (`safeLink`), each made by the service from checked fields; any other value gives no link (test).
- Independent code review: a 401 closes the popup and signs out (as every screen does); only the newest run may change the popup (a run number), and nothing changes after Close; Search and Try again wait while a run is active. "No place was found" keeps only Close, as approved: the service answers the same empty rescue again, so a new search after an empty answer needs a service rule (open).
