### D116. Write the server new; keep its wire contract
- https://dev.meta.ai/docs/image-understanding — the request shape the server sends (POST /v1/responses, `input_image` as a `data:` URL; the text in `output[].content[].text`). Read 2026-10-22 for the prior work; this session could not open the page again, so nothing new is taken from it.
- The prompt is kept byte for byte (a test pins its sha256), with the eight fields, the routes, the status codes and the error texts: the app and the inference service use them, and the eval results were measured with this prompt.

### D117. Find the JSON object with an index search, not a regular expression
- https://pkg.go.dev/strings@go1.24.7#IndexByte and https://pkg.go.dev/strings@go1.24.7#LastIndexByte — the first `{` and the last `}`, the same span as the old `(?s)\{.*\}` match. The fuzz test above found no input where the two differ.

### D118. The rate limit removes idle addresses
- https://go.dev/ref/spec#For_range — "If a map entry that has not yet been reached is removed during iteration, the corresponding iteration value will not be produced." So the prune can delete keys while it ranges over the map.
- When a new address comes and the map has 4096 addresses, every address with no hit in the window is removed, and the others keep only their recent hits. Before, every address stayed in memory until a restart. The answer to each request does not change.
- The review found that the first version did not write the shorter list of hits back, so a recent hit could count two times (a 429 too early); fixed, with a test. The prune runs at most one time per window, so many live addresses do not make each request scan the map (measured: 0.33 µs per request with 20,000 live addresses).

### D119. The request id has no fallback
- https://pkg.go.dev/crypto/rand@go1.24.10#Read — "Read fills b with cryptographically secure random bytes. It never returns an error, and always fills b entirely." The module needs Go 1.24 (`go.mod`), so the fallback path of the old code could never run.

### D120. One write and a sync for each metrics line
- https://pkg.go.dev/os@go1.24.7#File.Sync — "Sync commits the current contents of the file to stable storage." The line is encoded first, then written with one call, then synced; the file is closed with its error checked.

### D121. The token check, the body cap and the prefix cut
- https://pkg.go.dev/crypto/subtle@go1.24.7#ConstantTimeCompare — "The time taken is a function of the length of the slices and is independent of the contents." (A token of the wrong length returns at once, as before.)
- https://pkg.go.dev/net/http@go1.24.7#MaxBytesReader — the body is capped before any decoding (photo size × 4/3 for base64, plus 4096 bytes).
- https://pkg.go.dev/strings@go1.24.7#CutPrefix — reads the token after "Bearer ".
- One change that the review found and that is kept: with no token check configured (`Auth` nil), the old server panicked on each request (the connection closed); the new one answers 401. The analyze command always sets it.

### D122. The Go module path stays `github.com/TwoThousandAndTwo2002/Icarus/server`
- https://go.dev/ref/mod#go-mod-file-replace — the `inference/` and `post/` modules (moved here with their history) use a `replace … => ../server` directive with this path. With the same path they build with no change to their files; a rename is a separate change.
