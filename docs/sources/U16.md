### D1. The touch-up contract

`POST /api/touchup?mode=light|background&photo_id=<id>` with no body gives a job (202); `GET /api/touchup/{id}` gives its state; `GET /api/touchup/{id}/photo` gives the edit. The service takes only `photo_id` (X36a).

- V3RDE touch-up service, post/touchup.go (branch services): https://github.com/TwoThousandAndTwo2002/V3RDE/blob/services/post/touchup.go

### D3. A job, asked for every 2 s

The public name is behind API Gateway, which stops a request at 30 s, so the edit runs as a job.

- Amazon API Gateway quotas (HTTP API, 30 s): https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-quotas.html
