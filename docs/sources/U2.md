# U2 — sources for each decision

Change: U2 (branch `ui`), the app base of V3RDE: Expo SDK 58, the app identity and the brand icons.

### D1. Start from Expo's blank-typescript template for SDK 58

`create-expo-app --template blank-typescript@sdk-58` makes `package.json`, `tsconfig.json`, `index.ts`, `App.tsx` and `.gitignore`. The template is an open-source dependency (MIT, 650 Industries), so it is labelled and its licence is in `mobile/third_party/`. SDK 58 is the SDK of the Hackathon work that U1 carried (`expo-audio` in `voicerec.ts`).

- Expo, create-expo-app, `--template` and `@sdk-58`: https://docs.expo.dev/more/create-expo/

### D2. Dependencies with `npx expo install`

`npx expo install` picks the version of each library that the installed SDK names, so the native modules match SDK 58. The list is what the functions of the app need now (camera and barcode, image picker, image manipulator, audio, fonts, web). Style libraries come with the new style guide. The template names `react-native` 0.88.1; `npx expo install --check` on the Mac (online, Expo's version data for SDK 58) names 0.88.0 and failed the first U2 run, so the app pins `react-native` 0.88.0. (The offline list inside the `expo` 58.0.21 package names 0.88.1; the CLI says that offline validation is unreliable, so the online answer decides.)

- Expo, create-expo-app and `npx expo install`: https://docs.expo.dev/more/create-expo/
- Expo, `expo` package (SDK 58): https://docs.expo.dev/versions/v58.0.0/sdk/expo.md

### D3. The app identity: V3RDE

T9 (Oct 28 2026): the app is V3RDE. Name and web title `V3RDE`; slug and scheme `v3rde`; Android package and iOS bundle ID `com.kkombuchaas.v3rde` (the earlier ID had the old project name). A new package ID makes a new app on the phone.

- Expo, app config (`android.package`, `ios.bundleIdentifier`, `scheme`): https://docs.expo.dev/versions/latest/config/app/
- Android, set the application ID: https://developer.android.com/build/configure-app-module#set-application-id

### D4. Permission texts

The camera, microphone and photo-library permission texts come from the config plugins of `expo-camera`, `expo-audio` and `expo-image-picker`. Each text says what V3RDE uses the permission for.

- Expo, Camera (config plugin): https://docs.expo.dev/versions/latest/sdk/camera/
- Expo, Audio (config plugin): https://docs.expo.dev/versions/latest/sdk/audio/
- Expo, ImagePicker (config plugin): https://docs.expo.dev/versions/latest/sdk/imagepicker/

### D5. `.env`: React Native's fetch stays the global fetch

"On Android and iOS, `expo/fetch` is also installed as the global `fetch`." "To keep React Native's built-in `fetch` as the global, set `EXPO_PUBLIC_USE_RN_FETCH=1` in your environment variables." The photo upload of the app sends React Native FormData parts (`{uri, name, type}`).

- Expo, `expo` package, `expo/fetch` API (SDK 58): https://docs.expo.dev/versions/v58.0.0/sdk/expo.md

### D6. `eas.json`: the preview profile builds an APK

"To generate an .apk, modify the eas.json by adding one of the following properties in a build profile": `"android": { "buildType": "apk" }`. The preview profile is for internal distribution (testers install the APK directly).

- Expo, build APKs for Android: https://docs.expo.dev/build-reference/apk/

### D7. `tsconfig.json`: the tests are not in the type check

The tests run with Node's type stripping (U1 D3) and import `.ts` files with the extension, so `tsc` leaves `tests/` out. `tsc` checks the app code.

- TypeScript, tsconfig `exclude`: https://www.typescriptlang.org/tsconfig/#exclude

### D8. The brand icons are pre-existing and labelled

T9 (Oct 28 2026): V3RDE uses the 7 Hungree icon files. They are Hungree LLC brand assets from before the Hackathon, so they are labelled as pre-existing (`NEW_WORK_UI.md`, UI 2). The change writes each file from the earlier repository and checks its sha256 against the audit.

- Expo, splash screen and app icon: https://docs.expo.dev/develop/user-interface/splash-screen-and-app-icon/

### D9. The checks of the app base

`npm ci` installs exactly `package-lock.json` (fresh). `npx expo config` loads `app.json` and its plugins and gives the identity of D3. `npx expo install --check` finds each dependency at the SDK's version. `npm test` runs the 11 tests. `tsc` and the web export start when `api.ts` and `logic.ts` exist.

- npm, npm ci: https://docs.npmjs.com/cli/v10/commands/npm-ci
- Expo CLI (`expo config`, `expo install --check`): https://docs.expo.dev/more/expo-cli/
