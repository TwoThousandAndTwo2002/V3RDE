### D218. The item's own box from the scan picks the mask
- The item photo record holds the box of the item in SAM's frame of the upload (`ItemPhotoMeta.Box`, `FrameW/H`; https://github.com/TwoThousandAndTwo2002/Icarus/blob/services/inference/photos.go). The cut is made again from the upload with that box, so the box is known in the cut's pixels.
- https://dev.meta.ai/docs/sam/reading-segmentation — each SAM instance has its own box and mask. The instance whose box matches the item's box best (IoU at least 0.3) is the item; another instance is added only when its box is at least 70% inside the item's box (one item in several masks). A neighbour of the same concept is left out.

### D219. The scan's name of the item is asked first
- https://dev.meta.ai/docs/sam/segmenting — one concept (a short noun phrase) per request. The analyze events hold the name of each box that became an item (`EventBox.Name`, `Item`); "ripe plantains" is asked before "food" and "fruit". In the service the app's item title takes this place.
