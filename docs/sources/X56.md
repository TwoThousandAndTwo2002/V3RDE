### D342. The written public name is v3rde
- https://datatracker.ietf.org/doc/html/rfc1034#section-3.6.2 — a name with no address record cannot be reached: links to the icarus name fail. The defaults of `V3RDE_PUBLIC_URL` and `FANOUT_LINK_BASE` and `ABOUT_URL` now use `https://v3rde.thehungreeapp.com`. A box environment that sets them keeps its value. Links already sent (old mails, old Facebook posts) still name icarus; only a DNS name for icarus (the SME) makes them work again.
