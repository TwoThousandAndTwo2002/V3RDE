# X31 — sources for each decision

Change: X31, the `/v1/inventory` service, the router route with dedup against live listings, the PE-only gate, Caddy routes, compose; SUP template v5. Design: `docs/inference_engine_design.md` D31–D38. Read 2026-10-26.

Own evidence: `inference/service_test.go` (6 tests), `router/inventory_test.go` (3 tests); a Caddy 2.8.4 run with a test backend (the strict client-IP rule picked the real client from `6.6.6.6, 198.51.100.9, 10.0.1.5`; the old routes kept the peer address).

### D31. The service lives in `inference/`, port 8087, with analyze's token and input formats
- https://www.rfc-editor.org/rfc/rfc6750 — RFC 6750, bearer token usage (`Authorization: Bearer`).
- https://pkg.go.dev/net/http#MaxBytesReader — the body is capped before it is read.
- https://pkg.go.dev/crypto/subtle#ConstantTimeCompare — the token check takes the same time for every wrong token (`analyze.Bearer`).
- T9 requirements R2–R4 (`docs/inference_engine_design.md` §1): same formats and auth as analyze, module `inference/`, port 8087, top level = the largest group.

### D32. PE-Core-S16-384 is the only gate, and it fails closed
- https://github.com/facebookresearch/perception_models — Meta Perception Encoder (PE-Core), Apache-2.0.
- https://github.com/apple/ml-mobileclip — the earlier gate's weights are under the research-only `apple-amlr` license, so they cannot ship.
- Own evidence: HELDOUT AUROC 0.981, catch 0.831, false retake 1.6% (X29 deploy head, `tools/hackathon/results/deploy_head_20261026T185715Z.json`); T9 decision 2026-10-26.

### D33. Limits: rate limit per client, photos at the same time, a daily spend cap
- https://owasp.org/API-Security/editions/2023/en/0xa4-unrestricted-resource-consumption/ — OWASP API4:2023: limit requests, concurrency and spend for paid third-party calls.
- https://www.rfc-editor.org/rfc/rfc6585#section-4 — 429 Too Many Requests.
- https://www.rfc-editor.org/rfc/rfc9110#name-503-service-unavailable — 503 for a temporary overload (busy, budget).
- T9 decision 2026-10-26: $20 per day. A photo reserves $0.10 (about 2× the X30b mean of $0.047) and settles at its real cost, so photos that run at the same time cannot pass the cap together; the spend is read back from the events file after a restart.

### D34. The real client address behind the load balancer and Apache
- https://caddyserver.com/docs/caddyfile/options#trusted-proxies-strict — Caddy `trusted_proxies`, `trusted_proxies_strict`, `client_ip_headers`.
- https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/X-Forwarded-For — the left-most address can be spoofed; read from the right, past the trusted proxies.
- Only the new routes use `{client_ip}`; `/api/analyze`, `/v1/analyze`, `/api/scan` keep `{remote_host}` (unchanged).

### D35. Dedup against the caller's live listings marks, it does not remove
- https://www.nngroup.com/articles/ten-usability-heuristics/ — error prevention, and user control and freedom: warn before a duplicate, let the user decide.
- T9 requirement R7: never list the same item twice. Only the caller's own active, unexpired listings count (two donors may list the same product). The names are matched with the engine's `normName` rules. A listings service that is down does not fail the scan (`"dedup": "unavailable"`).

### D36. One event line per request, with every call and its cost
- https://jsonlines.org/ — one JSON object per line, as the telemetry sidecar ships.
- https://man7.org/linux/man-pages/man2/fsync.2.html — each line is synced, so the spend in the file is the spend the budget restores.
- T9 requirement R6: every call and every photo reports its cost.

### D37. The inventory image: repo-root context, its own ignore file, a memory ceiling
- https://docs.docker.com/build/concepts/context/#filename-and-location — `<Dockerfile>.dockerignore` next to the Dockerfile.
- https://pkg.go.dev/runtime#hdr-Environment_Variables — `GOMEMLIMIT`, a soft limit for the Go heap.
- https://docs.docker.com/reference/compose-file/services/#mem_limit — `mem_limit` for the container (the box has 1.9 GiB).

### D38. SUP template v5: the inventory Dockerfile and the Caddyfile are checked
- https://docs.docker.com/reference/cli/docker/buildx/build/#check — `docker buildx build --check`.
- https://caddyserver.com/docs/command-line#caddy-validate — `caddy validate` with the pinned `caddy:2.8.4` image.
