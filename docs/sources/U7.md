# U7 — sources for each decision

Change: U7 (branch `ui`), the food-doodle wallpaper of V3RDE: 20 new drawings placed and animated by the cellular automaton rule 30.

### D1. New art, not the earlier art

The earlier sign-in screen had a doodle wallpaper from before the kickoff. T9 asked (Oct 29) for new doodles with more variety, placed by a cellular automaton. The 20 drawings are new SVG paths on a 24-unit grid with round ends. Two independent checks compared them with the earlier art; the last one found no copy or near copy, and the bowl and the cup were drawn again after the first check.

- SVG path data: https://www.w3.org/TR/SVG2/paths.html
- react-native-svg (MIT): https://github.com/software-mansion/react-native-svg

### D2. Rule 30 makes each cell live or dead

Rule 30 is an elementary cellular automaton (Wolfram's numbering): each cell of the next row comes from the cell above and its two neighbours. The first row is random from a fixed seed (a linear congruential generator), so the start is the same each time; the edges wrap.

- Wolfram MathWorld, Rule 30: https://mathworld.wolfram.com/Rule30.html
- Wolfram MathWorld, Elementary Cellular Automaton: https://mathworld.wolfram.com/ElementaryCellularAutomaton.html
- Numerical Recipes LCG constants (1664525, 1013904223): https://en.wikipedia.org/wiki/Linear_congruential_generator#Parameters_in_common_use

### D3. A drawing in every cell; the pattern shows as strength

A first version drew only in the live cells; the check found large empty patches. Now every cell has a drawing, so the cover is even, and a dead cell's drawing is fainter (T9: "show the automaton").

- U7 review page (the first version and the measures): https://claude.ai/artifact/LWF5t8uurZM3HFP26Hpwnm

### D4. The animation and its values (T9, Oct 29)

T9 chose the values from an animated sample page: a new generation every 1000 ms comes in at the bottom and the pattern moves up one row; dead cells at 55 %; wallpaper 9 % (the earlier value). Only the strength of the drawings changes; the drawings, their turns and their places stay. With "reduce motion" on, the pattern stands still.

- The animated sample T9 used: https://claude.ai/artifact/1z3vseA6m5BtbRBAJuLimb
- WCAG 2.1, animation from interactions (reduce motion): https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions.html
- React Native, AccessibilityInfo.isReduceMotionEnabled: https://reactnative.dev/docs/accessibilityinfo#isreducemotionenabled

### D5. The hash: fair picks, no two neighbours the same

A hash of the cell (FNV-1a, then the murmur3 finalizer fmix32) picks the drawing, its turn and its shift, with a separate salt for each. The first version used the low bits of FNV-1a alone and showed only 17 of 20 drawings; with fmix32 the counts pass a chi-square test. When a pick is the same as the drawing to the left or above, the next drawing is taken.

- FNV hash: http://www.isthe.com/chongo/tech/comp/fnv/
- MurmurHash3 fmix32: https://github.com/aappleby/smhasher/blob/master/src/MurmurHash3.cpp

### D6. Look values from the earlier wallpaper

Opacity 0.09 (dark 0.10) and stroke 2.2 pt are the earlier values. The 38 pt cell keeps the ink per area near the earlier wallpaper (measured as the mean difference from the background in empty areas of the shots).

- WCAG 2.1, non-text contrast (decoration is exempt): https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast.html

### D7. Hidden from screen readers, no touches

The wallpaper is decoration: `aria-hidden` on the web, hidden on iOS and Android, and it takes no touches.

- React Native, accessibility (aria-hidden, importantForAccessibility): https://reactnative.dev/docs/accessibility
