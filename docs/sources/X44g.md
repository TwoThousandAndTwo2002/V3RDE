### D178. The donors' own corrections are the truth
- https://ai.meta.com/research/publications/sam-3-segment-anything-with-concepts/ — SAM 3 gives a box for each instance; the box size is what the engine's size limits act on.
- The app reports, for each item of a posted scan, the model's title and servings and the donor's final ones, and whether the item was kept (X32g, `POST /api/analyze/labels`). That is what the donor really posted, so it is the label. The report counts only the label sets with outcome `posted`; it joins each one to its scan line (same `request_id`), where every box of every item is logged (X32a).

### D179. The size limits are tuned on the size that Muse read
- https://dev.meta.ai/docs/image-understanding — "Coordinates are relative to the image the model actually received" (read 2026-10-26, quoted in `inference/prepare.go`).
- NameMinPx (64) and ConfidentPx (96) are short sides in the image Muse reads, set by hand from the v3 hand check (`inference/engine.go`). The report puts each labeled item in a size group by the same measure (`PreparedSize` and `SeenSize` of its largest box), so a group lines up with the limits it can move: under 64, 64 to 96, 96 to 128, 128 to 192, 192 and up.

### D180. A suggestion only from enough labels, and a person decides
- https://sol.utstat.utoronto.ca/modules/module-6/7-2-Confidence-Intervals-for-Proportions.pdf — "The margin of error for a 95% confidence interval for p is" a formula with the sample size n under the square root: a share from few labels is not exact.
- A suggested ConfidentPx needs at least 20 kept items in its size group and in each bigger group, each with at least 95% of the names unchanged. With fewer labels the report says so and suggests nothing. The report changes no setting: the flag is changed by a person, through a SUP change, so the pipeline improves from the donors' corrections with a human check.
- The day table is the series for the accuracy chart over the pilot (F10): counts only, from the events files of the box (`docker run --rm --entrypoint /calibrate -v <analyze events>:/events:ro v3rde-analyze`).
