# U9 — sources for each decision

Change: U9 (branch `ui`), reset password by email link.

### D1. Reset by an email link (T9, Oct 29)

T9 chose "Email link" for the reset. The request screen gives the same answer for every email, and the link works one time for a short time.

- OWASP Forgot Password Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html

### D2. The token is in the URL fragment

The link is `/reset#token=…`. A browser does not send the fragment to the server, and a Referer header has no fragment, so the token is not in a web server log. On the web the app removes it from the address bar with `history.replaceState`.

- RFC 3986, section 3.5 (fragment): https://www.rfc-editor.org/rfc/rfc3986#section-3.5
- RFC 9110, section 10.1.3 (Referer: no fragment): https://www.rfc-editor.org/rfc/rfc9110#section-10.1.3
- MDN, History.replaceState: https://developer.mozilla.org/en-US/docs/Web/API/History/replaceState

### D3. The token form: 32 random bytes, unpadded base64url

32 bytes give 43 base64url characters without `=` (Go `base64.RawURLEncoding`). The app accepts only `A-Z a-z 0-9 - _`.

- Go, encoding/base64 (RawURLEncoding): https://pkg.go.dev/encoding/base64#pkg-variables

### D4. The app link

The phone opens `v3rde://reset#token=…` (the scheme `v3rde` of app.json); the app reads the first link at start and the links that come later.

- React Native, Linking: https://reactnative.dev/docs/linking

### D5. Focus and screen readers

The new-password field gets the focus when the link opens it; "Check your email" is a polite live region, so a screen reader reads it when it comes.

- WAI-ARIA 1.2, aria-live: https://www.w3.org/TR/wai-aria-1.2/#aria-live
- React Native, TextInput (autoFocus, autoComplete new-password): https://reactnative.dev/docs/textinput

### D6. One independent check

T9 (Oct 29) set at most one independent check of at most 15 minutes. It found 5 issues (the token in the server log, a padded token, a blank screen on a start error, no focus on the new screen, a screen change while a request waits); T9 chose the fragment link and the fixes; all are fixed and checked with Playwright in the real app.
