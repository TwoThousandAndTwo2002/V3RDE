# U17 — sources for each decision

Change: U17 (branch `ui`), voice changes on the review.

### D1. The voice contract

`POST /api/voice` (multipart: `audio` WAV, `items` JSON of item, title and servings, `pickup_text`, `lang`) gives a proposal: `changes`, `new_items` (with `needs_photo`), `pickup_text`, `unclear`, `transcript`. The app posts nothing from it.

- V3RDE voice service, post/voice.go (branch services): https://github.com/TwoThousandAndTwo2002/V3RDE/blob/services/post/voice.go
- Meta, speech to text (Muse Voice Transcribe): https://dev.meta.ai/docs/speech-to-text

### D2. Tap to talk

A tap starts and a tap stops (no hold on a small button; it also works with a screen reader and a keyboard). The clip stops by itself before the service limit (voicerec.ts, UI 1).

- WCAG 2.1, pointer gestures: https://www.w3.org/TR/WCAG21/#pointer-gestures

### D3. Show, then apply

The proposal shows one line for each change, and the user applies it or keeps the list; the photo stays the source of truth.

- Nielsen Norman Group, visibility of system status: https://www.nngroup.com/articles/visibility-system-status/

### D4. A new item needs a photo

The listings service needs a photo for each listing, so an item that was only said is shown as not added.

- V3RDE listings service (branch services): https://github.com/TwoThousandAndTwo2002/V3RDE/tree/services/listings
