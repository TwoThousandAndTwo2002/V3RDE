### D215. The combo: Muse Image bigger first, then the studio blur on that edit
- T9's choice above. Muse Image gives the sharp detail that code cannot add (X48g page: the code edits of the 170-250 px cereal boxes were soft); the studio blur then isolates the item. The mask is found on the Muse edit itself, so the cut matches its pixels.
- https://dev.meta.ai/docs/image-generation — Muse Image edits keep "the rest intact" when the prompt says what stays; the check of D217 refuses the edits that do not.

### D216. The container of the food stays: SAM is also asked for plate, bowl, food tray, takeout container
- https://dev.meta.ai/docs/sam/segmenting — one concept per request, so the container concepts run as their own requests at the same time as the food concepts.
- A container is kept when its box holds at least half of the food mask: the tray around a meal is kept; a container elsewhere in the photo is not.
- https://foodshot.ai/blog/ai-food-photos-delivery-apps — the serving vessel is part of what the customer gets ("Re-plating in a clean version of the vessel you actually serve in" is the allowed edit); removing it misrepresents the item.
