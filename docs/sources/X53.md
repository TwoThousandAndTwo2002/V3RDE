### D336. One header block for every answer
- https://caddyserver.com/docs/caddyfile/directives/header — "Prefix the field name with `-`" deletes a header, and deletions are deferred until the response is sent (so `-Server` also removes a header a service sets). A delete line makes the whole block deferred, and a deferred block is not run when a service cannot be reached (the 502 then had no header: X53 review), so `header -Server` is a line of its own and the block has no delete. `handle_errors` (https://caddyserver.com/docs/caddyfile/directives/handle_errors) answers the edge's own errors with the same status and an empty body, as Caddy did before, with no `Server` header; the page's own example sets HSTS, nosniff and X-Frame-Options together. X-Frame-Options is SAMEORIGIN, not DENY: the assessment rates framing as low risk (the session cookie is SameSite=Lax), and SAMEORIGIN keeps any page of the app's own origin able to frame it.

### D337. The CSP is Report-Only first
- https://docs.w3cub.com/http/headers/content-security-policy-report-only — (MDN text) the header lets a site try a policy: the browser reports what it would block and blocks nothing. A wrong enforced policy would stop the app (the map, the photo previews, the voice step). It is enforced only in a later change, after its reports on the box are checked.
- https://Developers.Google.com/maps/documentation/javascript/content-security-policy — Google's allowlist policy for the Maps JavaScript API (`script-src ... https://*.googleapis.com https://*.gstatic.com *.google.com https://*.ggpht.com *.googleusercontent.com blob:`, `img-src`, `connect-src`, `font-src https://fonts.gstatic.com`, `style-src ... https://fonts.googleapis.com`, `worker-src blob:`, `frame-src *.google.com`). The app loads the map script from maps.googleapis.com (`mobile/src/maps.ts`). `script-src` has no `'unsafe-inline'`: the app page has no inline script, and the one inline script of the web build (the doodles of the about page, `mobile/public/about/index.html`) is allowed by its sha256 hash (https://Developer.Mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy/script-src — "Policies for inline resources with hashes like `script-src 'sha256-{HASHED_INLINE_SCRIPT}'` allow scripts and styles by their hash, but not event handlers"; the about page has no event-handler attribute: 0 reports). A test hashes every inline script of every page in the web build; a change of that script fails it until the hash in the Caddyfile is updated. `img-src blob:` is for the photo previews (`URL.createObjectURL`). `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'self'` close what the app does not use.

### D338. HSTS for one day first
- https://wiki.owasp.org/index.php?oldid=113810&title=HTTP_Strict_Transport_Security — a browser that got the header uses only https for the name until max-age ends; a long max-age cannot be taken back from browsers that already have it. One day (86400 s), with no includeSubDomains (other names under the domain are not in this repo). A longer time is a later change.
