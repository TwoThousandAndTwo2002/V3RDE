### D273. A static page next to the app, copied by the web build
- https://docs.expo.dev/guides/publishing-websites/ — "Any files inside the public directory are also copied to the dist directory." The page is `mobile/public/about/index.html`, so `npx expo export -p web --output-dir web-dist` puts it at `web-dist/about/index.html`, outside the app bundle (T9: "Separate static site"). `public/assets/` is reserved by Metro (same page), so the page uses `public/about/`.
- T9 (Oct 30): the address is `icarus.thehungreeapp.com/about/`.

### D274. The address has the trailing slash; the local server does the same as the edge
- https://caddyserver.com/docs/caddyfile/directives/try_files — "To match directories, append a trailing forward slash `/` to the path." The edge (`deploy/Caddyfile`) has `try_files {path} /index.html` and then `file_server`, so `/about/` matches the folder and file_server serves its index file; `/about` (no slash) is a file path that is not there, so it gets the app's `index.html`.
- https://github.com/caddyserver/caddy/issues/5033 — a file_server debug log shows the default `"index_filenames":["index.html","index.txt"]`.
- So the link is `/about/` (`ABOUT_PATH`), and `mobile/tools/web/serve.mjs` serves a folder's `index.html` only for a path that ends in `/` (test: `/about/` → the page, `/about` → the app, a folder with no page → the app).

### D275. Every value is a token; the page carries them as CSS custom properties
- https://www.w3.org/TR/css-variables-1/ — custom properties hold the values once (`--gap: 8px`, `--card: #FFFFFF`), and the rules use `var(--gap)`. Each one has the value of its `theme.ts` token (1 pt = 1 CSS px, as the mockups). The S3 style test reads only `src/` and `App.tsx`, so `mobile/tests/about.test.mts` checks the page: colours = `palette` (light and dark), lengths = `space`, `radius`, `size`, `glyph`, opacity = `opacity` and `doodle`, the text classes = `type`, the breakpoints and widths = `layoutFor`; no other colour, px length or fraction.
- https://www.w3.org/TR/WCAG21/#contrast-minimum — the text colours are the `palette` pairs that the style test already holds to 4.5:1 in both modes.

### D277. The backdrop is the app's doodle wallpaper, behind the whole page
- https://claude.ai/artifact/2uNoqikPjqa1nfCvJbGh1t — T9 (Oct 30): "use the background currently behind all pages for the backdrop of this web page." The page draws the same 20 drawings as `mobile/src/doodles.tsx`, with the same hash, generator and rule 30 as `mobile/src/automata.ts` and the same `doodle` tokens; it moves up one row each `doodle.stepMs`, as the app. The test compares the drawings and the constants with the app files.
- https://docs.w3cub.com/css/@media/prefers-reduced-motion — the `reduce` value "indicates that a user has enabled the setting on their device for reduced motion": then the pattern stands still, as the app does with "reduce motion".
- https://www.w3.org/WAI/WCAG21/Understanding/pause-stop-hide — 2.2.2 asks for a way to pause moving information that lasts more than 5 s. The wallpaper is decorative, at 9 % (10 % dark), the same as the app's approved screens; it also stops while the tab is hidden. Open question to T9: a pause control for the page and the app.
- https://www.w3.org/TR/SVG2/styling.html#PresentationAttributes — a presentation attribute takes a plain value, so the colour comes in through `style="stroke: var(--doodle)"`, and it changes with the mode without a redraw.

### D278. The fonts are the app's own Poppins files
- https://tug.ctan.org/fonts/gentium/OFL-FAQ.txt — OFL FAQ 2.5/2.6: a subset or an optimised web font is a Modified Version. The page uses the app's unchanged files (`font.regular`, `font.semibold`), which the web build already has under `/assets/` with a content hash, so there is no new font file and no modified one. The test checks that `web-dist` has the files the page names.
- https://docs.expo.dev/guides/publishing-websites/ — the font files are part of the export, at the same content-hashed paths as long as the font does not change.
