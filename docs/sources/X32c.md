Change: X32c, single items first and a 25 s limit. The whole-photo Muse call starts at the same time as SAM; 0 or 1 box (or boxes all too small to name) uses its answer with no agent; the photo limit is 25 s, under API Gateway's 30 s. Decisions by T9, 2026-10-27 ("lets impliment 1 and the limit to 25 seconds"; option B "whole call in parallel"). Read 2026-10-27.

Own evidence:
- Box ledger (2026-10-27): the app's kombucha photo got 0 SAM boxes on 3 of 3 tries; the agent took 35.3–41.3 s; the service answered 200 each time while the web app showed "The food scanner is busy".
- From the Mac: the same photo through `https://icarus.thehungreeapp.com/v1/analyze` got 503 `{"message":"Service Unavailable"}` at 30.3 s (HTTP/2 and HTTP/1.1); `GET /healthz` carries `apigw-requestid`; `aws apigatewayv2 get-domain-names` lists the name as an API Gateway custom domain; the box resolves the name to private addresses and got 200 at 37.5 s.
- Bench: `tools/hackathon/results/inference/compare_x32c.json` (from `tools/hackathon/compare_x32c.py`), `probe_x32c_live_20261027T190540Z.json`, `probe_x32c_early_20261027T191106Z.json`: 24 photos, live engine vs early whole call, each run alone with its own SAM calls.

### D57. The whole-photo call starts with SAM; 0 or 1 box uses it, no agent
- https://dev.meta.ai/docs/image-understanding — the whole call is analyze's single-image request (one image, the contract prompt, JSON answer), so it needs nothing from SAM and can start first.
- https://dev.meta.ai/docs/pricing-rate-limits — parallel requests fit the rate limits; the unused early call on 2+ photos is billed like any call (the bench measures it).
- https://pkg.go.dev/context — the early call shares the photo's context, so the 25 s limit stops it too.
- Bench (`compare_x32c.json`, groups by SAM's first find): 0 boxes, 3 photos: wait median 33.0 s → 2.7 s; 1 box: 9.9 s → 6.0 s; 2+ boxes, 20 photos: 14.0 s → 14.1 s median, cost $0.8710 → $0.9831. Photo `185749`: 2 listings from the agent, 1 from the early call (T9 chose speed).

### D58. The photo limit is 25 s
- https://docs.amazonaws.cn/en_us/apigateway/latest/developerguide/http-api-quotas.md — HTTP API "Maximum integration timeout | 30 seconds | No" (cannot be raised).
- https://repost.aws/knowledge-center/api-gateway-timeout-limit — only Regional and private REST APIs can raise the integration timeout; HTTP APIs are not in that list.
- T9 2026-10-27: "the limit to 25 seconds"; the target is every photo under 20 s.
