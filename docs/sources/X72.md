### D384. Two views: a short one first, the detail on a tap
- https://www.nngroup.com/articles/progressive-disclosure/ — progressive disclosure: show the few most important options first and the rest on request; it improves learnability, efficiency and error rate. Overview (open first) is the summary and the three-layer drawing; In depth is the six drawings. T9's names, not "simple" or "technical".
- https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/radio — radio buttons: one of a group is chosen, the arrow keys move between them, and each has a label; a `fieldset` with a `legend` names the group. The views are two radio inputs with labels styled as the app's role-tab pills, and CSS (`:checked`, `:has()`) shows one view (a browser with no `:has()` shows both): no script, so the page's one inline script and its CSP hash (deploy/Caddyfile) stay the same (the edge test checks the built page).
