### D407. The answer items on the event line
- https://developers.google.com/machine-learning/guides/rules-of-ml/ — Rule #29: "The best way to make sure that you train like you serve is to save the set of features used at serving time". Here: what the model answered is kept on the line of the request, next to the labels of the same request_id.
- `answer` is a list of `{item, fields, via, count, check, tray}`: `fields` are the 8 contract fields as the 200 answer has them (the barcode catalog's fields for a barcode hit); `via` is `Item.Source` (whole, single, single-N for the calls of a split, retry, agent, two-pass; a group of boxes takes the value of its first box) or `barcode`. An error line has no items. No user text and no photo are in it (the photo ids are already on the line, X41a).
