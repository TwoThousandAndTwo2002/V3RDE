### D221. Step 1: the scan's box as a SAM box prompt (the established way)
- https://pyimagesearch.com/2026/01/19/grounded-sam-2-from-open-set-detection-to-segmentation-and-tracking/ — Grounded-SAM: "Each detected box is passed to SAM 2 (or SAM) as a prompt", one mask per box. Our scan is the detector.
- https://dev.meta.ai/docs/sam/segmenting — a box prompt is `<0f>1<|box;x1=...;y1=...;x2=...;y2=...;w=...;h=...|>` in the text part, w/h the size of the sent image; the answer is one record per object id with a one_bit mask; one kind of prompt per request.

### D222. Step 2: one positive point and not-this points on the other objects (SAM-PD)
- https://arxiv.org/html/2403.04194 — SAM-PD: a box stage first, then a refinement that "samples one positive prompt ... inside" the first mask, and "we append points sampled from other objects as negative prompts"; it reports that negative points can make a mask unstable, so the page shows step 1 and step 2 side by side.
- https://dev.meta.ai/docs/sam/segmenting — the points of one object follow its id, a negative point is written with a leading "-": `1<|point;...|>-<|point;...|>`. The other objects are every other box of the same scan (the analyze events), any outcome. An object whose centre is inside the item's own box is not used (the item's plate or tray, or the item again: independent review), and with no other object the step is not run (the box result, paid once).
