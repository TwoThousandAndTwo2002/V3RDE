### D226. The service runs the "auto" column of the X48m page, and only the masks the scene rule needs
- https://dev.meta.ai/docs/cookbook/image-editing-with-reasoning — the Muse Image edit, named change first and then what stays (the X48g prompt).
- https://dev.meta.ai/docs/sam/segmenting — SAM 3.1 concept and box prompts (the words mask and the box mask).
- https://pyimagesearch.com/2026/01/19/grounded-sam-2-from-open-set-detection-to-segmentation-and-tracking/ — a detector's box as the SAM prompt (the box mask, X48k step 1).
- https://www.cns.nyu.edu/~lcv/pubs/makeAbs.php?loc=Wang03 — SSIM: the check of the Muse edit is in code (SSIM >= 0.75 and the same shape), so a new picture is refused without a Muse Spark call.
- https://foodshot.ai/blog/ai-food-photos-delivery-apps — delivery apps allow a new background, light and sharpness, and ban changed food: every food pixel comes from the photo or from an edit with the photo's structure, so the result is stored as done.
- The scan's item name is read only from the analyze events of the record's day and the next day (`ItemScanNear`, independent review): a job never reads the whole event history. The service runs this touch-up only with `-v2` (compose sets it).
- The box mask is asked for only when the words mask spills past the item's box or is missing (X48m rule): one SAM call less for most photos.

### D227. "light" is the Muse bigger edit only; "background" is the full auto touch-up
- https://dev.meta.ai/resources/blog/build-with-muse-Image — Muse Image edits keep the photo and change what the prompt names.
- The app keeps its two choices (`mobile/src/screens/TouchUp.tsx`): "light" makes no SAM call and no new background; "background" is the X48m auto column. No app change.

### D228. The touch-up container gets 640 MB (GOMEMLIMIT 560 MiB) and reserves $0.06 per job
- https://go.dev/doc/gc-guide#Memory_limit — GOMEMLIMIT is a soft limit for the Go heap; it is set under the container limit.
- https://docs.docker.com/reference/compose-file/services/#mem_limit — the compose memory limit of a service.
- The pictures are worked on in code at full size (float planes), two jobs at a time (`-max-in-flight 2`); 256 MB was set for the old edit, which only passed bytes on.
- The reserve is the most that one job can spend before it settles (X48l: words $0.195 / 6 photos, box $0.1225 / 6, Muse $0.06 / 6); the real cost settles the hold.
