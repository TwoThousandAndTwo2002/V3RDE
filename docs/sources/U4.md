### D3. Four helpers written new, then compared with the earlier ones

`itemPhotoPath`, `targetSize`, `joinUrl` and `errorMessage` replace pre-kickoff helpers that the carried code and the client use. They are new code with the same results. A comparison script (`v3rde_ui/u4_parity/par.mts` in the transfer folder on T9's Mac, with its output; run with Node type stripping) ran the earlier and the new helpers on the same 899 inputs (sizes with 0, negative, NaN and edge values; bases and paths with and without slashes; statuses 0–504 with nine body shapes; photo IDs); none differed.

### D4. `api.ts`: a new client for the routes of branch `services`

The routes and form fields are those of the services as written on branch `services` (`a184a05`): `POST /api/auth/signup|login|logout`, `GET /api/auth/me`; `GET /api/listings` (cursor `after`), `GET /api/listings/mine`, `POST /api/listings`, `POST /api/listings/{id}/grab`; `POST /api/analyze` (`image`, `barcode`, `capture`), `GET /api/analyze/photo/{id}`, `POST /api/analyze/labels`; `POST /api/voice` (`audio`, `items`, `pickup_text`, `lang`). Each request has a time limit (AbortController); the session cookie goes with each request (`credentials: "include"`); a phone reads a photo as a data URI (FileReader).

### D5. Rewrite guard

A rewritten file must not hold the code it replaces. The script carries the sha256 of every line of the earlier `api.ts`, `logic.ts` and `logic.test.mts` that the blame gives to the pre-kickoff snapshot (12 or more non-space characters). No line of the new files, outside the carried blocks, has one of them.

- Git, git-blame: https://git-scm.com/docs/git-blame

### D6. `tsc` from this change on

With `api.ts` and `logic.ts` here, every import of the app code resolves, so `tsc --noEmit` runs in the checks. The tests stay out of the type check (U2 D7) and run with `npm test` (25).
