### D346. The Report-Only CSP allows the learn page's inline script
- https://Developer.Mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy/script-src — "Policies for inline resources with hashes like `script-src 'sha256-{HASHED_INLINE_SCRIPT}'` allow scripts and styles by their hash". The learn page (`mobile/public/learn/index.html`) has one inline script; its sha256 is now in `script-src` next to the about page's (X53). ### D347. A push test reads today's events file
- https://pkg.go.dev/time#Now — the events file of the push service is named by the day the line is written (`Events.now`, the clock, not the test's fake time). `TestPush` and `TestPushPingByKey` read the file of their fake date (2026-11-01), so they failed on any other day (seen on Nov 2). The events log of these tests now has the test's fake clock, so it writes and reads the file of the fake date, also when a run crosses midnight UTC.

### D349. A rescue test waits for the second job's events line
- https://pkg.go.dev/testing#T — a test must not depend on the order of background writes it does not wait for. `TestRescueUsesTheStoreBeforeTheWebSearch` (X50b) read the events with `rescueEvents`, which waits for `"async":true`; the first job's line already has it, so the read could come before the second job's line (seen once in the push test of this change: "events {...}" with only the first line).
