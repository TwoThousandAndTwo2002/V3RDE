# X49h — sources for each decision

Change: X49h (UI), the Give cards: Delete as an X in a frosted round button on the photo, and Rescue as a pill the size of the time pill (`mobile/src/ui.tsx`, `mobile/src/screens/Give.tsx`, `mobile/tests/listing.test.mts`, `mobile/docs/style_guide.md`; NEW_WORK.md 78). T9 (2026-10-31), the approved "V3RDE Give And Review Mockup" (version 2): "i don like the size of the rescue pill its too large it should be the same size as the timer pill and the text should be that size too. delete should be an X with a semi opaque frosted circle like the delete button on a multi listing." The note of the rescue work (summary 2026-10-31): "Delete on a listing card → an X at the top right of the photo in a round button with an opaque circle."

Own evidence: mobile tsc and tests 126 -> 127; the mockup (real code, web export, dark mode) showed the X and the small pill on phone and desktop. The mockup also found that the frosted layer of a round part drew a square blur on the web: the blur and the tint now take the corners of the part.

### D273. Delete is a frosted round X on the photo
- https://m3.material.io/components/icon-buttons/overview — an icon button for a common action, with a touch target larger than the icon; `size.iconSmall` with the touch area grown to `size.iconBig` (as the item remove X of the review).
- https://www.w3.org/TR/WCAG21/#non-text-contrast — the frosted disc (the frosted layer of the sheets) keeps the X readable on any photo.

### D274. Rescue is the size of the time pill
- T9's words: the Rescue pill takes the width, the padding and the text style of the time pill above it. The pill is small, so its touch area grows by `space.group`: https://www.w3.org/WAI/WCAG21/Understanding/target-size.html (a target of at least 44 by 44 CSS pixels).
