# U3 — sources for each decision

Change: U3 (branch `ui`), the Android package and the iOS bundle ID become `com.kkombuchaas.V3RDE`.

### D1. Upper case `V3RDE` in the package ID

T9 (Oct 28 2026): V3RDE is upper case in the package ID. The Android application ID allows it: "It must have at least two segments (one or more dots). Each segment must start with a letter. All characters must be alphanumeric or an underscore [a-zA-Z0-9_]." The iOS bundle ID allows it too: "only alphanumeric characters (A-Z, a-z, 0-9), hyphens (-), and/or periods (.)", and "Bundle IDs are case insensitive."

- Android, configure the app module (application ID rules): https://developer.android.com/studio/build/application-id.html
- Apple, bundle ID: https://developer.apple.com/help/glossary/bundle-id

### D2. The URL scheme stays lower case

"Scheme matching in the Android framework is case-sensitive, unlike the RFC. As a result, always specify schemes using lowercase letters." So the scheme stays `v3rde`.

- Android, `<data>` element (`android:scheme`): https://developer.android.google.cn/guide/topics/manifest/data-element?hl=en
