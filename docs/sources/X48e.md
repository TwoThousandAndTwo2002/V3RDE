### D206. The frame is flex 1 (it can shrink), so the list scrolls inside it
- https://reactnative.dev/docs/layout-props — "`flex: <positive number>` equates to `flexGrow: <positive number>, flexShrink: 1, flexBasis: 0`"; `flexShrink` "accepts any floating point value >= 0, with 0 being the default value."
- The frame had `flexGrow: 1` only: with `flexShrink` 0 (react-native-web 0.21.4, `View` base style `flexBasis: 'auto', flexShrink: 0`) it grew to the height of the whole list, so the ScrollView inside had nothing to scroll and Receive never asked for its next page. `flex: 1` + `minHeight: 0` bound it to the window.

### D207. One title row for both roles; the user's own listings only under Give
- https://reactnative.dev/docs/layout-props — `minHeight` keeps a row at least that high; the title row of both screens is `size.control` high (`ScreenHead`), the height of the "+ New listing" pill, so the pill no longer moves the Give title down.
- T9's words above: Receive is for food of others. A grab of an own listing was refused already (403 "cannot grab your own listing"); now it is not shown. The filter is in the app (`othersOnly`). A page of only own listings adds nothing on the screen, so no scroll and no size change would ask again: one load asks for pages until a page brings food of others, the feed ends, or 5 pages (`loadOthers`, from the independent review). While pages remain and none is shown, the list says "Loading", not "Nothing is offered now".
