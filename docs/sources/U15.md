# U15 — sources for each decision

Change: U15 (branch `ui`), the review of the found items and Post.

### D1. The layout of the approved X32 mockup

One item: the form; several items: the review list with a card for each item; the photo at the left on a wide screen.

- U5 parts review (the X32 states): https://claude.ai/artifact/42WvX7iM3A8Bcc73AFtiUL

### D2. One listing for each item, one after the other

The listings service takes one listing for each request; the app posts the items in order and keeps the failed ones.

- V3RDE listings service (branch services): https://github.com/TwoThousandAndTwo2002/V3RDE/tree/services/listings

### D3. The checks before the request

The form checks are the listing limits of the listings service (title 1 to 80, servings 1 to 99, pickup 1 to 200).

- WCAG 2.1, error identification: https://www.w3.org/TR/WCAG21/#error-identification

### D4. The label report

What the user did with the answer (kept, removed, changed titles and servings) goes one time to `/api/analyze/labels` (X32g).

- V3RDE analyze server (branch services): https://github.com/TwoThousandAndTwo2002/V3RDE/tree/services/server

### D5. The keyboard over the form

On iOS the sheet rises with the keyboard (KeyboardAvoidingView).

- React Native, KeyboardAvoidingView: https://reactnative.dev/docs/keyboardavoidingview
