# U11 — sources for each decision

Change: U11 (branch `ui`), the app frame.

### D1. ☰ header on a phone and a tablet, a top bar on a wide screen

The earlier app had a ☰ header that opens the role sheet on a phone and a tablet, and a top bar with the role tabs and Log out on a desktop. The expanded window size class gets the top bar.

- Material Design 3, window size classes: https://m3.material.io/foundations/layout/applying-layout/window-size-classes
- Material Design 3, navigation (tabs): https://m3.material.io/components/tabs/overview

### D2. The safe-area package

Expo SDK 58 apps draw edge to edge on Android; react-native-safe-area-context gives the insets of the status bar and the home bar. The version is the one Expo SDK 58 pins (`expo/bundledNativeModules.json`: ~5.10.1).

- Expo, safe areas: https://docs.expo.dev/develop/user-interface/safe-areas/
- react-native-safe-area-context: https://github.com/AppAndFlow/react-native-safe-area-context

### D3. Tabs for the roles

The top-bar roles are a tab list: role `tablist`, each tab `tab` with `aria-selected`.

- WAI-ARIA Authoring Practices, tabs: https://www.w3.org/WAI/ARIA/apg/patterns/tabs/

### D4. A toast for short messages

A short message at the bottom, read by a screen reader at once (a polite live region).

- WAI-ARIA 1.2, aria-live: https://www.w3.org/TR/wai-aria-1.2/#aria-live

### D5. Colour contrast of the new pairs

The chosen tab (`link` on `accentSoft`) and the toast (`bg` on `fg`) reach 4.5:1 in both modes (tested).

- WCAG 2.1, contrast (minimum): https://www.w3.org/TR/WCAG21/#contrast-minimum
